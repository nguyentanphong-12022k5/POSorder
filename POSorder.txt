# 🧋 Cấu trúc & Prompt xây dựng App Order Đồ Uống có in hóa đơn

Dưới đây là bộ khung đầy đủ: **kiến trúc → cấu trúc thư mục → data model → luồng in → bộ prompt theo giai đoạn** để bạn đưa cho AI (Cursor, Claude Code, Copilot, v0…).

---

## 1. Gợi ý Tech Stack

| Thành phần | Lựa chọn khuyến nghị | Ghi chú |
|---|---|---|
| Frontend | **Next.js 14 (App Router) + TypeScript + Tailwind + shadcn/ui** | Dễ deploy, SSR tốt |
| State | Zustand (giỏ hàng) | Nhẹ, đơn giản |
| Backend | Next.js API Routes / Route Handlers | Không cần server riêng |
| Database | **Supabase (Postgres)** hoặc SQLite + Prisma | Supabase có Auth + Realtime |
| Auth | Supabase Auth (email/password cho nhân viên) | |
| In hóa đơn | **PDF (pdfkit/puppeteer)** + **react-to-print** | Web fallback |
| In nhiệt (thermal) | **node-thermal-printer** (ESC/POS qua LAN/USB) | Cho quán thực tế |
| Thanh toán | QR (VietQR) / Tiền mặt | MVP dùng tiền mặt trước |

## 4. Data Model (Prisma/SQL)

```prisma
model Category {
  id       String   @id @default(cuid())
  name     String
  sort     Int      @default(0)
  products Product[]
}

model Product {
  id         String   @id @default(cuid())
  name       String
  categoryId String
  basePrice  Int                 // VND, integer
  imageUrl   String?
  isActive   Boolean  @default(true)
  category   Category @relation(fields: [categoryId], references: [id])
  variants   Variant[]
  toppings   ToppingOnProduct[]
  orderItems OrderItem[]
}

model Variant {                  // S / M / L
  id        String  @id @default(cuid())
  productId String
  name      String               // "Size L"
  extraPrice Int    @default(0)
  product   Product @relation(fields: [productId], references: [id])
}

model Topping {                  // Trân châu, thạch...
  id       String @id @default(cuid())
  name     String
  price    Int
  products ToppingOnProduct[]
}

model ToppingOnProduct {
  productId String
  toppingId String
  product   Product @relation(fields: [productId], references: [id])
  topping   Topping @relation(fields: [toppingId], references: [id])
  @@id([productId, toppingId])
}

model Order {
  id           String      @id @default(cuid())
  code         String      @unique  // HD0001
  createdAt    DateTime    @default(now())
  status       OrderStatus @default(PAID)
  subtotal     Int
  discount     Int         @default(0)
  total        Int
  paidAmount   Int
  changeAmount Int         @default(0)
  paymentMethod PaymentMethod @default(CASH)
  note         String?
  staffId      String?
  items        OrderItem[]
}

model OrderItem {
  id         String  @id @default(cuid())
  orderId    String
  productId  String
  name       String                  // snapshot
  variantName String?
  toppings   String                  // JSON snapshot
  unitPrice  Int
  quantity   Int
  lineTotal  Int
  note       String?
  order      Order   @relation(fields: [orderId], references: [id])
  product    Product @relation(fields: [productId], references: [id])
}

enum OrderStatus { PAID, CANCELLED }
enum PaymentMethod { CASH, TRANSFER, CARD }
```

> **Quan trọng:** `OrderItem` phải **snapshot** tên món, giá, topping tại thời điểm mua — để sau này đổi menu không làm sai hóa đơn cũ.

## 5. Luồng in hóa đơn — chọn 1 trong 3

| Cách | Ưu điểm | Nhược |
|---|---|---|
| **A. `window.print()` + CSS `@media print`** | 0 dependency, chạy trên mọi máy | Không đẹp bằng máy in nhiệt |
| **B. PDF (pdfkit) → tải/xem** | Chuẩn hoá, lưu trữ được | Cần server render |
| **C. ESC/POS qua `node-thermal-printer`** | Đúng chuẩn máy in bill (Xprinter, Epson TM-T82…) | Cần cấu hình IP/USB |

**MVP:** làm **A + B song song**. **Production quán:** bật thêm **C**.

## 6. Bộ Prompt theo giai đoạn (copy-paste)

### 🔹 Prompt 0 — Khởi tạo dự án

```

- Next.js 14 App Router + TypeScript + Tailwind + shadcn/ui
- Zustand cho cart state
- Prisma + Supabase (Postgres)
- Cấu trúc thư mục: app/(pos), app/(admin), app/api, components, lib, types

Yêu cầu:
1. Tạo package.json với đầy đủ dependencies
2. Cấu hình tailwind, tsconfig, .env.example (NEXT_PUBLIC_SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY, DATABASE_URL, SHOP_NAME, SHOP_ADDRESS, SHOP_PHONE)
3. Tạo lib/money.ts: hàm formatVND(n) => "12.000 ₫" và parseVND
4. Tạo types/index.ts chứa interface Product, Order, OrderItem, CartItem
5. Chưa cần UI, chỉ cần skeleton chạy được `npm run dev` không lỗi.

Xuất toàn bộ file dưới dạng code block có đường dẫn.
```

### 🔹 Prompt 1 — Database & Seed

```
Dựa trên schema Prisma sau, hãy:
1. Viết file prisma/schema.prisma hoàn chỉnh (Category, Product, Variant, Topping, Order, OrderItem như spec)
2. Viết prisma/seed.ts seed dữ liệu mẫu: 3 category (Cà phê, Trà sữa, Đá xay), 10 sản phẩm, mỗi sản phẩm có 3 size S/M/L (M +0, L +6000), 5 topping (Trân châu 5k, Thạch 5k, Pudding 7k, Kem cheese 10k, Shot espresso 8k)
3. Viết lib/supabase.ts export 2 client: browser + server (service role)
4. Viết script tạo mã đơn dạng HD0001 tăng dần (dùng bảng Counter hoặc max+1 trong transaction)

[chèn schema ở mục 4]
```

### 🔹 Prompt 2 — Màn hình POS (menu + cart)

```
Xây dựng trang app/(pos)/page.tsx — màn hình bán hàng dạng 2 cột (desktop) / tab (mobile):

CỘT TRÁI — Menu:
- Fetch /api/menu (trả về categories có products + variants + toppings)
- Hiển thị category tabs ngang, grid product card (ảnh, tên, giá từ, badge nếu hết hàng)
- Click product → mở Dialog chọn: Variant (radio S/M/L), Toppings (checkbox), Note (textarea), Quantity (+/-), hiển thị tổng tiền realtime → nút "Thêm vào giỏ"

CỘT PHẢI — Cart:
- Zustand store: items[], addItem, removeItem, updateQty, clear
- Hiển thị từng dòng: tên + variant + topping, đơn giá, số lượng, thành tiền, nút xoá
- Bottom: tạm tính, nút "Thanh toán" (disabled nếu rỗng)
- Nút "Xoá giỏ" có confirm

Yêu cầu:
- TypeScript strict, không dùng any
- Responsive: mobile hiển thị cart dạng bottom sheet
- Sử dụng shadcn/ui: Dialog, Button, Input, Checkbox, RadioGroup, Sheet
- Tiền hiển thị bằng formatVND từ lib/money
- Toast khi thêm/xoá (sonner)

Xuất code đầy đủ từng file.
```

### 🔹 Prompt 3 — Checkout & tạo đơn

```
Xây dựng app/(pos)/checkout/page.tsx và API POST /api/orders:

UI Checkout:
- Danh sách item (readonly), tổng tiền
- Nhập giảm giá (VNĐ hoặc %)
- Chọn phương thức: Tiền mặt / Chuyển khoản
- Nếu tiền mặt: nhập "Khách đưa" → tự tính "Tiền thối" (không cho < tổng)
- Nút "Xác nhận & In bill"

API POST /api/orders:
Input: { items, discount, paymentMethod, paidAmount, note }
Xử lý:
1. Mở transaction Prisma
2. Sinh mã code HDxxxx (dùng script ở Prompt 1)
3. Snapshot tên/giá/top của từng item (không join lúc đọc lại)
4. Tính subtotal, total = subtotal - discount, changeAmount
5. Lưu Order + OrderItem
6. Trả về order đầy đủ

Sau khi tạo thành công: clear cart, redirect tới /orders/[id] kèm query ?print=1
Xử lý lỗi rõ ràng, trả status 400/500 kèm message.
```

### 🔹 Prompt 4 — Trang xem hóa đơn & in PDF

```
Xây dựng:
1. components/invoice/InvoiceTemplate.tsx — component thuần hiển thị hóa đơn khổ 80mm:
   - Header: SHOP_NAME (env), địa chỉ, SĐT, căn giữa
   - Tiêu đề "HÓA ĐƠN THANH TOÁN", mã đơn, giờ in (dd/MM/yyyy HH:mm)
   - Bảng items: Tên (+ variant, + topping), SL, Đơn giá, Thành tiền
     → dùng font monospace, cột căn phải, chiều rộng 72 ký tự (mô phỏng 80mm)
   - Dòng: Tạm tính, Giảm giá, TỔNG CỘNG (in đậm, to)
   - Tiền mặt / Tiền thối
   - Footer: "Cảm ơn quý khách! Hẹn gặp lại 🌸"
2. app/(pos)/orders/[id]/page.tsx — render InvoiceTemplate + nút "In" và "Tải PDF"
3. app/api/invoice/[id]/route.ts — dùng pdfkit sinh PDF khổ 80mm, trả về Content-Type application/pdf
4. Thêm CSS @media print ẩn mọi thứ trừ InvoiceTemplate, khổ giấy 80mm, margin 3mm.

Style: đen trắng, không màu, không border-radius, font 12-13px.
```

### 🔹 Prompt 5 (tuỳ chọn) — In máy in nhiệt ESC/POS

```
Viết lib/printer/escpos.ts dùng thư viện node-thermal-printer:

- Hàm printReceipt(order): kết nối tới máy in theo env PRINTER_INTERFACE (vd: tcp://192.168.1.100:9100), in:
  * Init, set codepage UTF8
  * alignCenter, bold: SHOP_NAME
  * alignLeft: mã đơn, ngày giờ
  * line, các item (name left, qty*price right)
  * line, TOTAL bold lớn
  * cut()
- Trả lỗi nếu không kết nối được, KHÔNG throw ra UI (chỉ log + toast)
- Route POST /api/print/[orderId] gọi hàm này
- Nút "In nhiệt" ở trang order, chỉ hiện nếu env ENABLE_THERMAL=true
```
